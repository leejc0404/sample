# 건강기능BM팀 인스타그램 운영 기획안 (v1.0)

작성일: 2026-09-04 / 담당: 건강기능BM팀 / 주기: 주 1회 발행

---

## 1. 왜 하는가 (목적)

| 구분 | 내용 |
|---|---|
| 궁극 목적 | 자사 건강기능식품의 **인지 → 호감 → 구매**로 이어지는 자연스러운 접점 만들기 |
| 중간 목적 | "건강기능식품 만드는 사람들"이라는 정체성으로 **신뢰 자산** 축적 |
| 부가 효과 | 팀 브랜딩 / 채용 매력도 / 내부 결속 |

**핵심 원칙 — 제품을 팔지 말고, 사람을 팔아라.**
제품 이야기부터 시작하면 광고 계정이 되고 팔로우가 안 붙습니다. 먼저 "이 팀 재밌네"를 만들고, 그 다음에 제품을 문맥 안에 끼워 넣습니다.

---

## 2. 계정 컨셉

> **"건강기능식품 만드는 사람들이 정작 제일 건강 안 챙김"**

- 한 줄 정의: 건강기능식품 BM팀 4~5명의 **단순한 선그림 일상툰 + 직장인 생존 팁**
- 톤앤매너: 자기비하 살짝, 과장 없음, 훈계 금지, 결론은 항상 "웃김 + 작은 쓸모"
- 화자: 팀의 막내 또는 관찰자 시점 1인 (일관된 "나"가 있어야 서사가 붙습니다)

### 왜 이 컨셉이 먹히는가
"건강 전문가 = 완벽한 사람"이라는 기대를 배신할 때 웃음이 생기고, 그 갭이 오히려 **"이 사람들 진짜 사람이네"**라는 신뢰를 만듭니다. 그리고 그 갭을 메우는 자리에 자연스럽게 제품이 들어갑니다.

## 3. 타깃

| 구분 | 정의 |
|---|---|
| 1차 | 25~39세 직장인 (특히 사무직). 점심 뭐 먹을지가 하루 최대 고민 |
| 2차 | 건강기능식품에 관심은 있으나 뭘 먹어야 할지 모르는 층 |
| 3차 | 업계 종사자 / 잠재 지원자 / 유통·MD 파트너 |

**페르소나 "김대리(31)"** — 아침 안 먹음, 점심에 매운 거 먹고 오후에 속 쓰림, 영양제는 사놓고 3일 먹다 서랍에 방치. 인스타 릴스로 하루를 마감.

## 4. 콘텐츠 필러 (3개 고정)

3개보다 많으면 계정 정체성이 흐려집니다. **3개만** 돌립니다.

### A. 팀 일상툰 (비중 50%) — 주력
- 4~8컷 캐러셀 인스타툰 또는 15~25초 릴스툰
- 소재: 점심 메뉴 전쟁, 회의실 정치, 시식 평가회, 출장, 마감 주간, 신제품 네이밍 회의
- 목적: **저장 + DM 공유** (알고리즘 최대 가중치 지표)

### B. 직장인 생존 팁 (비중 30%)
- "회사에서 안 졸고 버티는 법", "점심 먹고 몰려오는 식곤증 원리", "회식 다음날 루틴"
- 형식: 5~7컷 캐러셀 (1컷 훅 → 중간 정보 → 마지막 CTA)
- 목적: **저장·공유 유도**. 여기가 나중에 제품이 들어갈 자리입니다.

### C. 업의 뒷이야기 (비중 20%)
- "이 원료가 제품이 되기까지 18개월", "왜 정제는 이렇게 크게 만드냐면요", "성분표 읽는 법"
- 목적: **전문성·신뢰**. 제품 직접 노출 단계에서 이 필러가 근거가 됩니다.

## 5. 캐릭터 설정 (4~5명)

캐릭터가 고정되어야 "다음 화"가 기다려집니다. 실명 대신 **별명 + 한 줄 특징 + 시각적 식별자 1개**로 정리하세요.

| 별명(예시) | 한 줄 특징 | 시각 식별자 | 역할 |
|---|---|---|---|
| 맵부심 K팀장 | 안 매운 건 음식이 아니라 주장 | 뿔테 안경 | 사건 유발자 |
| 유산균 J님 | 영양제 20종 복용, 근데 야식 | 포니테일 | 정보 제공자 |
| 무맛 P대리 | 사내 유일 순한맛파, 늘 옳았음 | 후드티 | 브레이크 |
| 막내 L (화자) | 다 휘말림, 기록 담당 | 단발 + 사원증 | 서술자 |
| (선택) 부장님 | 등장만으로 분위기 전환 | 넥타이 | 특별 출연 |

> ⚠️ 실제 팀원 얼굴·실명·직급을 그대로 쓰면 초상권/인사 이슈가 생깁니다. **캐릭터는 실존 인물이 아닌 '조합된 인물'로 설정**하고, 팀원 전원에게 사전 동의를 받으세요. (11번 참조)

### 그림 스타일 가이드
- 검은색 단선(1.5~2pt) + 무채색 + **포인트 컬러 1개**(브랜드 컬러 권장)
- 얼굴은 점 두 개 + 선 하나 수준으로 단순화 → 그리기 부담 ↓, 일관성 ↑
- 배경 최소화 (책상 선 1개, 창문 사각형 1개면 충분)
- 도구: 굿노트/프로크리에이트/미리캔버스/Canva 중 팀에서 가장 손 빠른 것 하나로 통일
- **템플릿을 만들어 두세요.** 인물 포즈 8종 + 말풍선 4종을 라이브러리화하면 1편 제작이 2시간 → 40분으로 줄어듭니다.

## 6. 발행 계획

| 항목 | 내용 |
|---|---|
| 빈도 | **주 1회 피드(툰) + 주 2~3회 스토리** |
| 요일/시간 | **화 또는 목 12:00~13:00** (점심시간 = 타깃 접속 피크) |
| 형식 배분 | 캐러셀 3 : 릴스 1 (월 4회 기준) |
| 리드타임 | 발행일 기준 **D-7 소재 확정 → D-4 콘티 → D-2 작화 → D-1 검수** |

주 1회는 시작으로 적절합니다. 다만 **스토리는 주 2~3회** 반드시 병행하세요. 피드만 주 1회면 알고리즘이 계정을 잊습니다.

## 7. 제품 노출 3단계 로드맵

제품을 언제 넣느냐가 이 계정의 성패입니다. **절대 서두르지 마세요.**

### 1단계 — 0~3개월 (1~12화): 제품 노출 0%
- 오직 재미와 공감. 제품·브랜드명 **전혀 등장 안 함**
- 회사명도 프로필에만, 콘텐츠에는 없음
- 목표: 팔로워 500~1,000, 저장률 확보, "톤" 정착

### 2단계 — 3~6개월 (13~24화): 간접 노출
- 배경 소품으로만 등장 — 책상 위 정체불명의 통, 회의실 시제품 박스
- "우리 회사 제품"이라고 말하지 않음. 알아보는 사람만 알아봄
- B필러(생존 팁)에서 **성분·원리는 설명하되 제품은 언급 안 함**
- 목표: 팔로워 2,000~3,000, DM 문의 발생

### 3단계 — 6개월+ (25화~): 직접 노출
- "저희가 만든 겁니다" 커밍아웃 편 → 제작 비하인드 시리즈
- 프로필 링크에 자사몰 연결, 하이라이트에 제품 스토리
- 이벤트/체험단, 인스타그램 쇼핑 태그
- ⚠️ **이 단계부터 광고 심의 대상**입니다. (11번 필수 확인)

## 11. 반드시 지킬 것 (컴플라이언스)

### ① 건강기능식품 광고 심의 — 3단계 진입 전 필수
건강기능식품을 표시·광고하려면 **자율심의기구(한국건강기능식품협회 등)의 사전 심의**를 받아야 합니다. SNS 게시물도 제품 광고에 해당하면 대상입니다.
- 3단계(제품 직접 노출) 진입 전 **사내 법무/RA 부서와 반드시 사전 협의**
- 심의받은 문구만 사용, 심의필 번호 표기
- **금지 표현**: 질병 예방·치료 효능 암시, 의약품으로 오인될 표현, 전문의 추천, "○○에 효과"류 단정
- 팀원 개인 후기도 회사 계정에 올리면 광고로 봅니다. 주의.

### ② 초상권·인격권
- 캐릭터는 실존 인물과 분리. 팀원 전원 **서면 동의** 확보
- 퇴사자 캐릭터 처리 방침을 미리 정해두기

### ③ 제3자 상표
- 첫 화의 "해주냉면"처럼 **실제 가게 상호는 쓰지 마세요.** → `ㅎㅈ냉면` / `평양냉면집` / `회사 앞 냉면집`으로 대체
- 타사 제품·로고 등장 금지

### ④ 사내 승인
- 계정 개설 전 홍보/마케팅 부서 승인 (사명 사용, 채널 중복 여부)
- 계정 소유권은 **개인 계정이 아닌 회사 이메일**로. 인수인계 대비
