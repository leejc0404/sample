# 인스타그램 계정 설정 체크리스트

개설 당일 30분이면 끝납니다. 순서대로 진행하세요.

---

## 0. 개설 전 (가장 중요)

- [ ] **회사 공용 이메일**로 가입 (`healthbm.official@회사도메인`). 개인 계정/개인 메일 절대 금지 — 담당자 퇴사 시 계정을 잃습니다
- [ ] 비밀번호는 사내 비밀번호 관리도구에 등록, 최소 2인 공유
- [ ] 홍보/마케팅 부서에 **사명 사용 및 채널 개설 승인** 받기
- [ ] 2단계 인증(2FA) 활성화 — 인증 앱 방식, 백업 코드는 팀 공유 드라이브에 보관

---

## 1. 계정 유형

- [ ] **프로페셔널 계정 → 비즈니스**로 전환
  - 설정 및 개인정보 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환
  - 크리에이터가 아닌 **비즈니스**를 선택 (연락처 버튼, 쇼핑 연동, 예약 도구가 필요합니다)
- [ ] 카테고리: **`개인 블로그`** 또는 **`디지털 크리에이터`**. 업종을 드러내는 카테고리는 쓰지 않습니다 (3단계에서 변경)
- [ ] 공개 계정 유지 (비공개면 인사이트·연동이 제한됩니다)
- [ ] Facebook 페이지 연결 → Meta Business Suite 접근 (예약 발행·광고 집행에 필요)

---

## 2. 프로필 세팅

### 사용자 이름(@handle)
검색과 기억에 직결됩니다. 짧고, 발음 가능하고, 밑줄·숫자 최소화.

후보 예시:
```
@1200to1300      @lunch.six        @noon.people
@twelve.ish      @after.lunch.log
```
> 업종·회사가 유추되는 단어(bm, health, 음료 등)는 쓰지 않습니다.
> 결정 전에 유사 계정 존재 여부와 상표 충돌을 반드시 확인하세요.

### 이름(Name) — 검색 최적화 필드
핸들과 다르게, **이름 필드는 인스타 검색 대상**입니다. 업종 없이, 검색될 말만 넣습니다.
```
점심시간 | 어느 회사 여섯 명
```

### 소개(Bio) — 150자
```
오전엔 조용하고 12시엔 좀 밝아지는
어느 회사 여섯 명

밥 15분, 카페 35분의 기록
```
- [ ] 3줄 구조: **상태 / 누구 / 무엇을**. 회사·업종·"인스타툰"·"팁" 같은 설명어 없음
- [ ] 해시태그·CTA 없음. 리센느식 — 계정이 스스로를 설명하지 않습니다
- [ ] 브랜드 전용 해시태그는 **팬이 만든 게 생기면 그걸 채택**. 우리가 먼저 만들지 않음

### 링크
- [ ] 1단계에서는 회사 홈페이지 또는 링크 없음
- [ ] 3단계 진입 시 자사몰 + **UTM 파라미터** 필수
  ```
  https://쇼핑몰주소/?utm_source=instagram&utm_medium=bio&utm_campaign=bmteam
  ```

### 프로필 사진
- [ ] 여섯 명 뒷모습 실루엣 또는 카페 컵 여섯 개. **얼굴 캐릭터를 프로필에 쓰지 않습니다** (캐릭터는 발견되게)
- [ ] 320×320 이상, 원형 크롭 기준으로 확인

---

## 3. 초기 콘텐츠 세팅

- [ ] **첫 게시물 전에 3편을 미리 만들어 두세요.** 방문자가 빈 계정을 보면 팔로우하지 않습니다. 개설일에 3편을 30분 간격으로 올리고, 이후 주 1회로 전환
- [ ] 하이라이트는 **`낙서`** 하나만. 스토리 낙서를 모아두는 용도. 캐릭터 소개·Q&A 하이라이트 금지
- [ ] 고정 게시물 없음. **캐릭터 소개편은 만들지 않습니다** (`docs/06-differentiation.md` 3절)

---

## 4. 도구 설정

| 메뉴 | 설정 |
|---|---|
| 인사이트 | 활성화 확인. 주간 확인 지표: 도달 / 저장 / 공유 / 프로필 방문 |
| 빠른 답장 | "어디 회사예요?"에 대한 답 없음. 협업·광고 제안 DM만 담당자 1인에게 |
| 댓글 필터 | 부적절 단어 자동 숨김 ON, 커스텀 단어에 경쟁사·비방어 추가 |
| 스팸 방지 | "잠재적 스팸 댓글 숨기기" ON |
| 예약 발행 | Meta Business Suite에서 화요일 12:30 예약 |
| 태그 허용 | 수동 승인으로 변경 (아무 계정이나 태그 걸면 리스크) |

---

## 5. 리스크 방어 (회사 계정이므로 필수)

- [ ] **응대 원칙 문서 1장** 작성 후 팀 공유
  - 제품 효능 질문 → "개별 상담은 어렵고, 공식몰 고객센터로 안내" (효능 답변 절대 금지)
  - 부정 댓글 → 삭제하지 말 것. 사실 확인 후 정중히 1회 답변, 그 후 무대응
  - 협업/광고 제안 DM → 담당자 1인에게 일원화
- [ ] **금지어 리스트** 팀 공유: 치료, 완치, 예방, 개선(단정형), 부작용 없음, 의사 추천, 국내 유일, 최고
- [ ] 3단계(제품 직접 노출) 진입 전 **법무/RA 협의 + 자율심의 신청** 일정 확보 (심의에 시간이 걸립니다)
- [ ] 팀원 캐릭터 사용 동의서 서면 확보

## 6. 개설 첫 주 액션

| 일자 | 액션 |
|---|---|
| D-day | 계정 개설, 프로필 완성, 게시물 3편 업로드 |
| D+1 | 팀원 개인 계정에서 스토리 공유 / 사내 공지 |
| D+2 | 유사 계정 30곳 팔로우 + 진성 댓글 10개 |
| D+3~7 | 스토리 매일 1개 (제작 과정, 오늘의 점심 등 가벼운 것) |
| D+7 | 인사이트 1차 확인 → 유입 경로 파악 |
