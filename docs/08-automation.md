# 자동화 컨셉 — "월요일 12:47 파이프라인"

꾸준함은 의지가 아니라 구조에서 나옵니다. **사람이 매주 하는 일을 20분 이내로** 줄이는 게 목표입니다.

---

## 0. 원칙

1. **이야기는 사람이, 나머지는 기계가.** 어떤 사건을 그릴지, 어떤 표정인지는 사람. 컷 배치·글자·캡션·발행은 자동
2. **낙서는 자동화하지 않는다.** 날것이 팬덤을 만듭니다. 여기에 기계가 들어가는 순간 죽습니다
3. **자동화된 결과물이 "못 그린 것처럼" 보여야 한다.** 깔끔하면 기획 티가 납니다

## 1. 그림체 — 자동화와 자연스러움을 동시에 만족하는 하나

### 결론: **점선체** (점 두 개, 선 하나)

| 후보 | 장점 | 문제 |
|---|---|---|
| **A. 점선체** — 원형 머리, 점 눈 2개, 선 입 1개, 막대 몸 | 누구나 그림. 파츠 조합 자동화 가능. 낙서 층과 같은 결 | 밋밋할 수 있음 → 식별자로 해결 |
| B. 굵은 라인 캐릭터 (브랜드 인스타툰 류) | 귀여움 | 작화 실력 필요. 담당자 1명에 의존 → 꾸준함 깨짐 |
| C. 실루엣 + 손글씨 | 분위기 | 표정 못 씀. 여섯 구분 안 됨 |

**A를 고릅니다.** 이유는 하나 — 여섯 명 중 누가 그려도 같은 그림이 나오고, 스크립트로도 같은 그림이 나옵니다. 담당자가 휴가 가도 발행됩니다.

### 점선체 규격 (렌더러 기준)

| 요소 | 규격 |
|---|---|
| 캔버스 | 1080×1350 (4:5), 여백 80 |
| 선 | 검정 `#111`, 굵기 6px. **자를 대지 않은 듯 살짝 흔들림** |
| 머리 | 원 지름 140. 완벽한 원 금지 (살짝 찌그러짐) |
| 눈 | 점 2개, 지름 10 |
| 입 | 선 1개. 감정 5종: `一` 무표정 · `⌣` 웃음 · `⌢` 곤란 · `○` 놀람 · `~` 애매 |
| 몸 | 직선 2개 (어깨선 + 몸통) 또는 사다리꼴 |
| 배경 | 없음. 테이블 선 1개, 시계 원 1개까지만 |
| 포인트 컬러 | **1개.** 카페 컵·시계·식판에만. 오늘 점심에 정함 |
| 글씨 | 대사는 손글씨체(나눔손글씨 붓 / 교보손글씨), 나레이션은 고딕 |
| 말풍선 | **없음.** 대사는 인물 머리 위 텍스트 + 짧은 선 1개 |

### 식별자 (캐릭터 구분은 오직 이걸로)

| 캐릭터 | 식별자 | 그리는 법 |
|---|---|---|
| 밝음이 | 웃음 효과선 3개 | 머리 오른쪽 위 짧은 선 3개. **항상** |
| 유행이 | 폰 | 손 끝에 세로 직사각형 |
| 믿음이 | 노트북 | 앞에 열린 ㄴ자 |
| 유연이 | 눈썹 일직선 | 눈 위에 가로선 1개. 유일하게 눈썹 있음 |
| 막내 | 사원증 | 목 아래 세로 직사각형 + 줄 |
| 대한이 | 컵 2개 | 양손에 컵. 소매선 |

> 오늘 점심에 **본인이 직접 고른 걸로 바꿔도 됩니다.** 단, 실제 본인 외모 특징은 피하세요 (안경, 머리 모양 등 → 특정됨).

## 3. 각 단계의 도구

### ① 소재 던지기 → 시놉 뱅크 아티팩트에 입력창 추가
지금 뱅크는 68편 고정입니다. **"오늘 나온 말" 입력창**을 붙여서 팀원 누구든 한 줄 던지면 `원료`로 쌓이게 합니다. 카톡에 던지면 흘러가고, 여기 던지면 남습니다.

### ③ 콘티 생성 → Claude 루틴 (매주 월 13:00)
매주 월요일 13:00에 Claude가 뱅크를 읽어 `생산` 상태인 소재를 찾고, 콘티를 만들어 `docs/episodes/EP-XX.md`로 저장합니다. 캐릭터 바이블·절대 규칙·힘숨찐 원칙이 프롬프트에 내장되어 **누구 한 명 바보로 끝나는 콘티는 나오지 않습니다.**

> ⚠️ 루틴 생성은 지침 문서 수정에 해당하므로 **확인 후 진행합니다.** (사용자 원칙)

### ④ 렌더러 → 콘티 JSON을 점선체 PNG로
```json
{ "cut": 3, "time": "12:00",
  "chars": [{"who":"밝음","mouth":"○","x":1},{"who":"유연","mouth":"一","x":4}],
  "line": {"who":"밝음","text":"아 진짜요??"},
  "nar": "" }
```
이런 JSON 한 줄이 컷 하나입니다. 브라우저에서 열리는 HTML 하나로 만들 수 있고, 1080×1350 PNG를 뽑아줍니다. **여섯 명 파츠는 SVG로 고정** → 누가 돌려도 같은 그림.

### ⑥ 발행 → 앱 내 예약
인스타 프로페셔널 계정은 앱에서 직접 예약 발행이 됩니다 (최대 75일). API 연동은 Facebook 페이지 연결이 필요해서 **회사 특정 리스크** — 쓰지 않습니다.
